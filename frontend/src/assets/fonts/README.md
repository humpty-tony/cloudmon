# Fira Code

Unmodified Fira Code 6.2 variable WOFF2, bundled locally for offline use.

Source: https://github.com/tonsky/FiraCode/releases/tag/6.2
Archive member: `woff2/FiraCode-VF.woff2`
License: SIL Open Font License 1.1, reproduced in `OFL-FiraCode.txt`.
SHA-256: `408e876a202f15ea6ee307a70a65cf40ceb222c589a0b17e0a3a371db96dd49f`

No runtime CDN or local-font installation is required. Contextual/programming ligatures are disabled so evidence and query operators retain their literal glyphs.
